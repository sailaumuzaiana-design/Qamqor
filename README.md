# Qamqor
# Qamqor — цифрлық платформа

## Жобаның сипаттамасы

Qamqor — мұқтаж адамдарға қажетсіз, бірақ пайдалануға жарамды заттарды тегін беруге арналған веб-платформа.

## Жобаның мақсаты

Адамдарға өздерінің пайдаланбайтын заттарын мұқтаж адамдарға тегін беруге мүмкіндік жасау.

## Жобаның өзектілігі

Көптеген адамдар пайдаланбайтын киімдерін, кітаптарын, балалар заттарын және тұрмыстық бұйымдарын сақтайды немесе тастайды. Qamqor платформасы заттарды қайта пайдалануға және өзара көмек мәдениетін дамытуға ықпал етеді.

## Негізгі функциялар

- Пайдаланушыларды тіркеу және жүйеге кіру
- Заттар туралы хабарландыру жариялау
- Заттарды атауы, санаты және қаласы бойынша іздеу
- Затты алуға өтінім жіберу
- Өз хабарландыруларын басқару
- Өтінімдерді қабылдау немесе қабылдамау
- Әкімші панелі арқылы бақылау
- Деректердің қауіпсіздігін қамтамасыз ету
